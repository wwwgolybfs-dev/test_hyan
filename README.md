# Petzker Cookware — Team App with Mini-Games 🎮

Полностью обновленное веб-приложение для Telegram с календарем выходных, дневником и **4 мини-играми**.

## 📦 Что вы получили

### Основные файлы:

| Файл | Описание |
|------|---------|
| **index.html** | Главное приложение (календарь + дневник + меню игр) |
| **dice.html** | 🎲 Игра с кубиками (улучшенная версия) |
| **minesweeper.html** | 💣 Классический минёр как на Windows |
| **doodle.html** | 🧑 Дудл Джамп с персонажем (толстый китаец) |
| **throne.html** | 👑 Терновый трон с джостиком |
| **SETUP_INSTRUCTIONS.md** | Подробная инструкция по настройке |

## 🎯 Ключевые улучшения

### 1. Новая вкладка "Игры" 🎮
- Красивое меню выбора 4 мини-игр
- Встраивается через iframe
- Легко переключаться между играми

### 2. Улучшенная игра с кубиками 🎲
✅ **Анализ доступных клеток**
- Скрипт анализирует поле и свободные ячейки
- Показывает только те фигурки, которые реально можно разместить

✅ **Визуальная обратная связь**
- Красные контуры для недопустимых позиций
- Зеленые контуры для допустимых позиций
- Статус-бар с информацией о доступных фигурах

### 3. Классический минёр 💣
✅ **3 уровня сложности**
- Easy: 8×8, 10 мин
- Medium: 12×12, 30 мин  
- Hard: 16×16, 40 мин

✅ **Рейтинг игроков**
- Сохранение лучших времен в Supabase
- Топ-5 лучших результатов
- Интеграция с профилем пользователя

✅ **Windows-стиль интерфейс**
- Классический внешний вид
- ЛКМ для открытия, ПКМ для флага

### 4. Дудл Джамп 🧑
✅ **Оригинальный персонаж**
- Толстый китаец в шортах и майке
- Майка подкатана (видна чиксий живот) 😄
- Анимированные глаза показывают направление

✅ **Игровая механика**
- Бесконечная игра (становится сложнее)
- Обычные платформы
- Пружинные платформы (дают бонус скорости)
- Частицы при приземлении
- Система очков и рекордов

### 5. Терновый трон 👑
✅ **Управление джостиком**
- Виртуальный джостик в левом нижнем углу экрана
- Плавное движение персонажа
- Поддержка сенсорного управления

✅ **Игровой процесс**
- Сбор золота (💰)
- Враги с каждой волной
- Система здоровья
- Растущая сложность
- Волновой режим

## 🚀 Быстрый старт

### 1. Загрузите файлы на GitHub Pages

```bash
# Создайте новый репозиторий на GitHub
git clone https://github.com/YOUR_USERNAME/petzker-cookware.git
cd petzker-cookware

# Скопируйте все HTML файлы
# Все файлы должны быть в одной папке

git add .
git commit -m "Add Petzker Cookware with mini-games"
git push origin main
```

### 2. Включите GitHub Pages

1. Перейдите в Settings вашего репозитория
2. Выберите Main branch как source для Pages
3. Приложение будет доступно по адресу: `https://YOUR_USERNAME.github.io/petzker-cookware/`

### 3. Обновите Supabase

Откройте SQL Editor и выполните команды из `SETUP_INSTRUCTIONS.md`:

```sql
-- Создайте таблицы для игр
CREATE TABLE minesweeper_scores (...)
CREATE TABLE dice_game_scores (...)
```

### 4. Обновите конфиг в index.html

```javascript
// Найдите строку:
const GAMES_BASE_URL = 'https://wwwgolybfs-dev.github.io/petzker-games/';

// Замените на:
const GAMES_BASE_URL = 'https://YOUR_USERNAME.github.io/petzker-cookware/';
```

## 🎮 Управление игр

### 🎲 Кубики
- **Мышь/Сенсор**: Перетащите фигуру на доску
- **Зеленый контур** = можно разместить
- **Красный контур** = нельзя разместить

### 💣 Минёр
- **ЛКМ**: Открыть клетку
- **ПКМ**: Поставить флаг
- **Клавиши**: Easy/Medium/Hard для выбора сложности

### 🧑 Дудл Джамп
- **Стрелки** или **A/D**: Движение влево/вправо
- **Сенсор**: Тащите влево/вправо

### 👑 Терновый трон
- **Джостик** (нижний левый угол): Управление движением
- **Сбор золота** автоматический при контакте

## 🔧 Особенности реализации

### Анализ доступных клеток (Dice Game)

Алгоритм проверяет:
1. ✅ Количество свободных клеток на доске
2. ✅ Возможность размещения каждой фигуры
3. ✅ Генерирует только те фигуры, которые можно поставить
4. ✅ Показывает статус в реальном времени

```javascript
function canPlaceAnywhere(piece) {
  for (let r = 0; r < BOARD_SIZE; r++) {
    for (let c = 0; c < BOARD_SIZE; c++) {
      if (isValidPlacement(getShapeCells(piece, r, c))) 
        return true;
    }
  }
  return false;
}
```

### Рейтинг игроков

Данные сохраняются в Supabase:
- Telegram User ID (для идентификации)
- Имя пользователя
- Результаты игры
- Время завершения

```javascript
await supabaseClient.from('minesweeper_scores').insert([{
  telegram_user_id: playerId,
  name: playerName,
  difficulty: 'easy',
  time: elapsedSeconds,
  completed_at: new Date().toISOString()
}]);
```

## 🎨 Кастомизация

### Изменить цвета

В `index.html` найдите `:root` CSS:

```css
:root {
  --blue: #2E7BEE;      /* Основной синий */
  --orange: #F0921A;    /* Апельсин */
  --green: #22C55E;     /* Зелень */
  --red: #EF4444;       /* Красный */
}
```

### Изменить игрока в Дудл Джамп

В `doodle.html` найдите `drawPlayer()` функцию и измените цвета/размеры:

```javascript
// Тело (живот)
ctx.fillStyle = '#F5B041';  // Персиковый цвет
```

## 🐛 Решение проблем

### Игры не загружаются

- ✅ Проверьте URL в `GAMES_BASE_URL`
- ✅ Убедитесь, что все файлы в одной папке
- ✅ Откройте консоль браузера (F12) и посмотрите ошибки

### Supabase не сохраняет

- ✅ Убедитесь, что таблицы созданы
- ✅ Проверьте RLS политики
- ✅ Посмотрите логи в Supabase

### Медленная загрузка

- ✅ Очистите кеш браузера
- ✅ Закройте другие вкладки
- ✅ Используйте свежий браузер
