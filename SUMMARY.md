
```
https://YOUR_USERNAME.github.io/petzker-cookware/
```

### Шаг 2️⃣: Настройка URL в коде

Откройте `index.html` и найдите строку 240:

```javascript
const GAMES_BASE_URL = 'https://wwwgolybfs-dev.github.io/petzker-games/';
```

**Замените на**:

```javascript
const GAMES_BASE_URL = 'https://YOUR_USERNAME.github.io/petzker-cookware/';
```

Сохраните и загрузите изменения на GitHub.

### Шаг 3️⃣: Обновление Supabase

Откройте **Supabase** → **SQL Editor** и выполните команды из `SETUP_INSTRUCTIONS.md`

**Минимально нужно создать таблицы для новых игр:**

```sql
-- Для минёра

  id BIGINT PRIMARY KEY GENERATED ALWAYS AS IDENTITY,

  name TEXT NOT NULL,
  score INT NOT NULL,
```

## 🎮 Как играть

### 🎲 Кубики
1. Перетащите фигуру мышью на доску
2. Зелёный контур = фигура может быть размещена ✅
3. Красный контур = фигура не может быть размещена ❌
4. Цель: собирать линии и получать очки

### 💣 Минёр
1. Выберите сложность (Easy/Medium/Hard)
2. ЛКМ - открыть клетку, ПКМ - поставить флаг
3. Не нажимайте на мину!
4. Откройте все безопасные клетки
5. Ваше время сохранится в рейтинге

### 🧑 Дудл Джамп
1. Используйте **стрелки** или **A/D** для движения
2. Прыгайте по платформам вверх
3. Красные пружинные платформы дают бонус
4. Падение = конец игры
5. Собирайте очки и побивайте рекорды

### 👑 Терновый трон
1. Используйте **джостик** (левый нижний угол) для управления
2. Собирайте золото (💰)
3. Избегайте врагов (💀)
4. С каждой волной враги быстрее
5. Цель: собрать как можно больше золота

## 🔧 Техническое резюме

### Архитектура

```
GitHub Pages (хостинг)
    ↓
index.html (главное приложение)
    ↓
    ├─→ iframe → dice.html
    ├─→ iframe → minesweeper.html
    ├─→ iframe → doodle.html
    └─→ iframe → throne.html
    
Supabase (база данных)
    ↓
    ├─ vacations (выходные)
    ├─ diary_entries (дневник)
    ├─ minesweeper_scores (рейтинг)
    └─ dice_game_scores (рекорды)

Telegram (интеграция)
    ↓
    ├─ Получение профиля пользователя
    ├─ Гаптическая обратная связь
    ├─ Поддержка темной/светлой темы
    └─ Полноэкранный режим
```

### Технологии

- **Frontend**: HTML5 + CSS3 + Vanilla JavaScript
- **Canvas**: Используется для Дудл Джамп и Терновый трон
- **Backend**: Supabase (PostgreSQL + Auth)
- **Hosting**: GitHub Pages (бесплатный)
- **Интеграция**: Telegram Web App API

## 📞 Если что-то не работает

### Игры не загружаются

1. Откройте Console в браузере (F12)
2. Посмотрите ошибки CORS
3. Проверьте что URL в `GAMES_BASE_URL` правильный
4. Убедитесь что все файлы на GitHub Pages

### Supabase не сохраняет

1. Откройте SQL Editor в Supabase
2. Проверьте что таблицы созданы
3. Посмотрите логи в "Realtime" вкладке
4. Убедитесь что RLS настроен правильно

### Медленная загрузка

1. Очистите кеш браузера (Ctrl+Shift+Delete)
2. Закройте другие вкладки
3. Используйте современный браузер
4. Проверьте интернет соединение
